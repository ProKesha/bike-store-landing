
# Bike Store Landing

A responsive landing page for a bike store built with HTML, SCSS, and JavaScript. The project focuses on semantic markup, adaptive layout, and accurate implementation of a provided design.

## Live Preview

[Demo link](https://prokesha.github.io/bike-store-landing/)

## Overview

This project presents a promotional website for a bike store with multiple structured sections, navigation, and interactive UI elements. It is designed to showcase clean layout development, responsive behavior, and attention to visual details.

## Technologies Used

- HTML5
- SCSS
- JavaScript (ES6)

## Features

- Responsive page layout
- Semantic HTML structure
- Navigation between page sections
- Hover effects and smooth interactions
- Clean and reusable styling structure
- Cross-device friendly design

## Notes

This project was created to strengthen layout and styling skills, with a focus on responsive design, semantic HTML, and pixel-accurate UI implementation.
